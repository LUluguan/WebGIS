技术路线
P-III 24h设计暴雨(广东查算图表) → 径流深(q=R×C) → 浴缸法反演水位 → 水深 = 水位 − 地形
在线模拟: 自定义雨量与径流系数 C → 实时反演 → 三维水体 + 影响统计
真实洪涝: Sentinel-1 RTC + Sentinel-2 光学 → 5波段 → UNet 水体提取 → 边界水位反演 → 水深
GeoScene: 淹没范围发布为 GeoScene Online 托管要素服务 → Cesium/GeoScene API 双端消费
数据源：GLO-30 DEM(去建筑) · Sentinel-1/2 卫星影像 · GF-FloodNet 训练集 · PostGIS(可选) · 天地图底图。全部仅供教学演示，不作工程依据。

▶ 建议演示流程（约 3 分钟）

  1. 0:00-0:40三维模拟：进入三维场景，依次点击 2年→100年 档位，观察水位上涨动画与"Unet正在反演中"过程；关注 6 个分区淹没标签与右侧受影响建筑/人口统计。
  2. 0:40-1:10易涝点：点击「易涝点 Top8」列表中任意一项，相机定位到具体淹没斑块，说明其面积与最大水深。
  3. 1:10-1:50在线模拟：切到「在线模拟」，输入 300mm、把径流系数 C 从 0.50 调到 0.35 对比淹没面积变化——展示海绵城市改造的规划决策价值；点击「播放 24h 淹没演进」观看降雨-涨水全过程。
  4. 1:50-2:30真实事件：切到「真实事件」，在英德/梅州两个真实洪涝事件间切换，讲解"卫星影像 → UNet → 水位反演"四步管线，切换 SAR 灾前/灾中图层展示洪水演进范围。
  5. 2:30-3:00数据大屏 + GeoScene：打开数据大屏总览指标，再打开 GeoScene 2D 分析页演示托管要素服务的过滤与查询，说明平台级部署。
