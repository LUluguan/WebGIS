# 真实洪涝事件模块设计：UNet 驱动三维水深模拟（北江 2022-06 · 英德）

日期：2026-08-13
状态：已获用户批准

## 1. 目标

在本工程（广东降雨洪涝 WebGIS，珠江新城三维场景）内新增**「真实洪涝事件」模块**，
完整闭环展示 **真实卫星影像 → UNet 提取水体 → 水位反演水深 → 三维可视化** 链路，
让 **UNet 实际产出本工程的三维水深**（而非仅作展示工具）。

用户明确要求：交付物必须体现 **UNet 对本次工程的实际作用（水深模拟）**。
故模块内的三维水深由 UNet 掩膜经边界水位反演得到，并在页面中醒目呈现该产出链路。

## 2. 背景与约束（已核实）

- **UNet 模型输入**：5 波段 uint16，训练尺寸 128×128，归一化用 checkpoint 的 per-band mean/std。
  5 波段来源 = **GF-2 多光谱 4 波段（蓝/绿/红/近红外）+ GF-3 SAR 单波段**（C 波段，2021-2022，1.5-4m）。
- **GF-FloodNet 数据集中无广东样本**：1621 个中国瓦片全部位于河南（33.9-35°N，2021 郑州"7·20"洪水），已逐瓦片扫描确认。
- **GF-2/GF-3 现势获取不可行**：需向资源卫星中心注册申请，指定区域+日期几乎无法在竞赛周期内完成。
- **光学（Sentinel-2）在广东洪涝期普遍被云覆盖**：已核查研究区与北江/梅州多个事件窗口（45%~100% 云）。
- **SAR（Sentinel-1，C 波段，与 GF-3 同类）可穿透云层**：是可靠捕捉真实洪涝的唯一现实路径。

## 4. 处理管线（新脚本 `realevent_beijiang.py`）

1. **下载**：对 S1 VV×2、S2 B02/B03/B04/B08+SCL、GLO-30 DEM，签名后用 rasterio `from_bounds` 窗口读取裁剪。
2. **统一网格**：全部重采样到 10m、裁剪到目标窗口、按窗口对齐（参考 S2 网格）。
3. **5 波段堆栈**：`[S2_B02, B03, B04, B08, S1_VV]`，尺寸→128×128，逐波段归一化（采用训练 mean/std，若分布偏差大则改用本影像统计，并记录于 event JSON）。
4. **UNet 推理**（复用 `unet_model.UNet` + `unet_out/unet_water.pt`）→ 洪水中水体概率 → 掩膜（prob>0.5）。
5. **水位反演**（复用 `water_level_inversion.invert`）：W = median(DEM[掩膜边界])，水深 D = max(0, W−DEM) 仅掩膜内。
6. **双通道验证**：
   - SAR 变化检测：06-26 VV vs 06-02 VV 后向散射骤降 → 新增水面掩膜，与 UNet 掩膜求 IoU；
   - 真彩叠加人工核验。
7. **导出**（写入 `realevent_out/`）：
   - `flood_mask.png`（UNet 掩膜）、`depth.tif`（水深栅格）、`depth.png`（蓝阶色带）、`truecolor.png`（S2 真彩）、`sar.png`
   - `realevent.json`（事件元数据 + W + 淹没面积 + 平均/最大水深 + UNet/SAR IoU + 四步缩略图路径）

## 5. 三维可视化 `realevent.html`（复用 flood.html 成熟模式）

**核心：三维水深由 UNet 产出，页面醒目呈现链路。**

1. **四步流水线看板**（页面顶部）：同步展示"影像 → UNet掩膜 → 水位W → 水深D"四步缩略图，
   每步标注方法与公式（如 `W = median(DEM[边界])`、`D = max(0, W−DEM)`）。
2. **图层开关**：真实卫星真彩 / UNet 掩膜 / 反演水深色带（SingleTile 叠加，复用 `setDepthLayer` 模式）。
3. **三维水深场**：水体面片在水位 W 处，按反演水深 D 着色；图例标注"水深由 UNet 掩膜反演"。
4. **统计面板**：反演水位 W、淹没面积 km²、平均/最大水深、UNet/SAR IoU、事件信息（时间/卫星/方法）。
5. **方法对比面板**：同一事件「UNet 反演水深」vs「若用浴缸体积法」（无影像假设法），
   凸显 UNet 从真实影像反演水位、无需水文假设的作用。
6. **相机**：定位到英德城区（113.42E, 24.19N 附近）。

## 6. 服务集成

- FastAPI（app.py）静态托管 `realevent.html`；
- 新增 `GET /api/realevent` 返回 `realevent.json` 数据（与前端 fetch 相对路径一致）；
- `index.html` 入口加「真实事件 · UNet 反演水深」链接。

## 7. 成功标准

- ✅ UNet 掩膜与 SAR 变化检测 **IoU > 0.7**；
- ✅ 掩膜与已知英德被淹范围目视吻合；
- ✅ 反演 W 与 2022-06 英德洪峰水位（约 35m）量级对应；
- ✅ 页面可演示：四步链路清晰、三维水深场正常渲染、统计面板正确。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 域迁移（GF-2/GF-3 → S2/S1） | 归一化适配 + SAR 变化检测验证；必要时以 SAR 变化掩膜为参考阈值兜底并标注 |
| 06-23 光学云 45% | SCL 云掩膜检查裁剪窗；云多则换 07-13（20% 云）光学 |
| S1 时机（06-26 非峰值当日） | 北江退水慢（英德被淹逾一周），仍为有效"洪水中"影像；以 06-02 基线对比佐证 |
| UNet 置信度波动 | 掩膜与 SAR 变化交集优先显示，event JSON 记录 IoU 与可靠性提示 |
| S1 VV 数值格式/量纲 | 实现时确认 COG 为线性幅度或 dB，归一化时统一处理并记录 |

## 9. 范围外（YAGNI）

- 不做研究区（珠江新城）的 UNet 应用（无洪涝影像，物理不可行）；
- 不做 GF-2/GF-3 申请（获取不可行）；
- 不做逐像素时序动态（单事件静态水深场 + 图层切换）。
